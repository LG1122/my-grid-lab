# Симуляція каскадних аварій в енергосистемі IEEE-118

**Етап 1 — Паралельні обчислення MIMD на CPU**

Програмний проєкт мовою Python для моделювання каскадних аварій в енергосистемі IEEE-118 методом Монте-Карло. Розробляється в межах навчальної дисципліни «Грід-системи та технології хмарних обчислень».

## Опис проєкту

Проєкт присвячений дослідженню стійкості енергосистеми за допомогою обчислювальних експериментів методом Монте-Карло. Моделюються початкові відмови ліній електропередачі, подальше поширення каскадних аварій та можливість виникнення системного блекауту.

Перший етап реалізації зосереджений на паралельному виконанні обчислень із використанням процесорних ядер та механізму `multiprocessing.Pool` мови Python.

## Технічний підхід

- **Метод моделювання:** Монте-Карло.
- **Тестова система:** енергосистема IEEE-118.
- **Архітектура паралельних обчислень:** MIMD (Multiple Instruction, Multiple Data).
- **Модель виконання:** багатопроцесорні обчислення Python (`multiprocessing`).
- **Керування процесами:** `multiprocessing.Pool`.
- **Модель відмов:** зважений випадковий вибір ліній електропередачі.
- **Критерій блекауту:** відносний недовідпуск потужності (DNS proxy) перевищує 5%.
- **Генерація випадкових послідовностей:** незалежні початкові значення генератора випадкових чисел для кожного робочого процесу.

### Алгоритм моделювання

1. Завантаження вибраного сценарію роботи енергосистеми.
2. Формування незмінного знімка топології мережі.
3. Розподіл обчислювальних випробувань між процесами CPU.
4. Генерація початкових відмов ліній електропередачі.
5. Моделювання каскадних аварій та перерозподілу навантаження.
6. Обчислення показників стійкості енергосистеми.
7. Агрегація результатів та вимірювання продуктивності.

## Показники продуктивності

У межах запланованих бенчмарків передбачається оцінювання таких показників:

- Загальний час виконання обчислень.
- Пропускна здатність (кількість випробувань за секунду).
- Прискорення порівняно з однопроцесорним режимом.
- Ефективність паралельних обчислень.
- Імовірність виникнення блекауту.
- Середнє та максимальне значення DNS proxy.
- Середня кількість відключень ліній у каскаді.
- Статистика відмов критичних ліній електропередачі.
